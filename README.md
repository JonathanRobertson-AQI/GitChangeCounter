# GitChangeCounter

A .NET 8 console app that counts lines of code **added** and **deleted** across locally cloned GitHub repositories, comparing two time periods side by side.

## Features

- Auto-discovers all git repositories under a root folder
- Prompts for two years and a month range (e.g. Jan–Mar) to compare
- Runs `git log --numstat` in parallel across all repos — no API calls, no rate limits
- Renders a colour-coded comparison table using [Spectre.Console](https://spectreconsole.net/)

## Requirements

- [.NET 8 SDK](https://dotnet.microsoft.com/download)
- `git` on your `PATH`
- Repos cloned locally

## Usage

```sh
dotnet run --project GitChangeCounter
```

You will be prompted for:

| Prompt | Example |
|---|---|
| Root folder containing cloned repos | `C:\code\myorg` |
| Year A (older) | `2024` |
| Year B (newer) | `2025` |
| Start month | `1` |
| End month | `3` |
